## File Guide
1. **01_cleaning.ipynb**: Jupyter notebook; loads every file used, applies each cleaning step in order, and prints the number of rows before and after each step, and shows the reason for each.
2. **Exploration.ipynb**: Jupyter notebook; visualisations, summary statistics and patterns, including comparisons between variables.
3. **R2_inputs_graph.png**: Image file; Visual representation of all possible meaningful inputs, denoted with arrows. 
4. **DATA_DICTIONARY.md**: Markdown file; contains descriptions of each feature in each raw CSV file.
