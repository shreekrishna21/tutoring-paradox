## Topic

## File Guide
1. R1_problem.md: Markdown file; problem statement, the decision, and four questions with goals.
2. <ins>R2_inputs_graph.png</ins>: Image file; Visual representation of all possible meaningful inputs, denoted with arrows. 
3. <ins>01_cleaning.ipynb</ins>: Jupyter notebook; loads every file used, applies each cleaning step in order, and prints the number of rows before and after each step, and shows the reason for each.
4. <ins>Exploration.ipynb</ins>: Jupyter notebook; visualisations, summary statistics and patterns, including comparisons between variables.
5. R5_hypotheses.md: Markdown file; two if-then hypotheses with predictions and planned tests.
6. <ins>DATA_DICTIONARY.md</ins>: Markdown file; contains descriptions of each feature in each raw CSV file.

## How to Run
1. Download the data files from the course repository
   (final-project/Topic5_Education_The_Tutoring_Paradox/data).
2. Put the CSV files in the same folder as the notebooks.
3. Run 01_cleaning.ipynb first (it saves the cleaned files), then Exploration.ipynb.
