## File Guide
1. <ins>01_cleaning.ipynb</ins>: Jupyter notebook; loads every file used, applies each cleaning step in order, and prints the number of rows before and after each step, and shows the reason for each.
2. <ins>Exploration.ipynb</ins>: Jupyter notebook; visualisations, summary statistics and patterns, including comparisons between variables.
3. <ins>R2_inputs_graph.png</ins>: Image file; Visual representation of all possible meaningful inputs, denoted with arrows. 
4. <ins>DATA_DICTIONARY.md</ins>: Markdown file; contains descriptions of each feature in each raw CSV file.
